# 🌿 Green Property Exchange

An interactive Object-Oriented Programming (OOP) Java Swing application developed for **CCPROG3** (Computer Programming 3) that implements the **Model-View-Controller (MVC)** architectural pattern.

## Project Description

The **Green Property Exchange** is a simulation platform designed for managing eco-friendly accommodations and handling customer reservations. It allows hosts to manage properties (Eco-Apartments, Sustainable Houses, Green Resorts, and Eco-Glamping), set base pricing, and adjust day-specific environmental modifiers (rates ranging from 80% to 120%). Guests can view a 30-day calendar of availability, book overnight stays with dynamic pricing calculations, and cancel existing bookings.

## Key Features
- **Sustainable Accommodations**: Multiple property types, each with custom pricing multipliers.
- **Dynamic 30-Day Calendar**: Interactive grid displaying availability and daily rates.
- **Dynamic Pricing Engine**: Calculates overnight rates dynamically using `Base Price * Property Multiplier * Environmental Modifier`.
- **Reservation Management**: Book or cancel date ranges with itemized receipts.
- **Interactive Swing GUI**: Seamless MVC navigation and inputs.
